3. `npx tsc --noEmit` がエラーなく終了すること。
4. 開発サーバーが起動していること（例: `http://localhost:3000`）。

## 4. API単体確認用 `curl` コマンド例

ブラウザ操作とあわせて、`T-09` のサーバー側バリデーション検証に利用するコマンド。

```bash
# 1. 正常系リクエスト
curl -i -X POST http://localhost:3000/ai/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"日本の首都はどこですか？一言で答えてください。"}'

# 2. 異常系：空文字（期待値: 400 Bad Request）
curl -i -X POST http://localhost:3000/ai/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"   "}'

# 3. 異常系：型不正（期待値: 400 Bad Request）
curl -i -X POST http://localhost:3000/ai/ask \
  -H "Content-Type: application/json" \
  -d '{"question":12345}'

```
